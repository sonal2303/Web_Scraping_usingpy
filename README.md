
# Web Scraping Using Python 🕷️

A simple Python project demonstrating the basics of **Web Scraping** using `Requests` and `BeautifulSoup`.

## 🛠️ Technologies

* Python
* Requests
* BeautifulSoup4
* HTML

## 📂 Files

* `00 fetching data.py` – Fetch webpage data
* `01 tags.py` – Extract HTML tags and content
* `webScraping ecom.py` – Scrape e-commerce data
* `data.csv` – Store scraped data
* `sample.html` / `modified.html` – HTML practice files

## ▶️ Installation

```bash
pip install requests beautifulsoup4
```

## 🚀 Run

```bash
python "00 fetching data.py"
python "01 tags.py"
python "webScraping ecom.py"
```

## 🎯 Objective

To learn how to **fetch, parse, extract, and store data from webpages using Python**.
